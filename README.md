# Agentix Content Bot

Это Telegram-бот для автоматической рассылки обучающего контента (марафона) на базе `aiogram 3.x` и базы данных `SQLite` (`aiosqlite`). 
Бот использует `APScheduler` для ежедневной автоматической рассылки материалов пользователям в 09:00 по московскому времени.

## Требования для сервера
- **Docker**
- **Docker Compose**

## Инструкция по деплою (Deploy Guide)

### 1. Клонирование репозитория
Склонируйте код на сервер и перейдите в папку проекта:
```bash
git clone https://github.com/USERTRYTOMAKE/bottg.git
cd bottg
```

### 2. Настройка переменных окружения
Для работы бота необходим токен. Создайте файл `.env` в корневой папке проекта:
```bash
nano .env
```
Вставьте туда токен вашего бота в следующем формате (без кавычек):
```env
BOT_TOKEN=ваш_токен_от_BotFather
```

### 3. Подготовка базы данных
Бот использует SQLite. В конфигурации `docker-compose.yml` прописан маунт (volume) для папки `data/`.
Перед первым запуском создайте эту папку, чтобы избежать проблем с правами доступа в Docker:
```bash
mkdir -p data
```

### 4. Запуск проекта
Соберите образ и запустите контейнер в фоновом режиме:
```bash
docker compose up -d --build
```

### 5. Проверка работы
Убедитесь, что контейнер успешно запущен и нет ошибок в логах:
```bash
docker compose logs -f
```

---

### Полезные команды для обслуживания

Остановить бота:
```bash
docker compose down
```

Перезапустить бота (если внесли изменения в код и сделали `git pull`):
```bash
docker compose up -d --build
```

Сделать бэкап базы данных (выполняется из папки проекта):
```bash
cp data/bot_database.db data/bot_database_backup.db
```
